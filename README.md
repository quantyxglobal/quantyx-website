# quantyx Global

## About

quantyx Global is a professional medico-legal services platform powered by AI technology. We provide expert medical chronologies, narrative summaries, and comprehensive legal document analysis to support legal professionals and medical experts.

## Features

- **AI-Powered Medical Chronologies** - Comprehensive timeline analysis of medical records
- **Narrative Summaries** - Clear, detailed medical narrative reports
- **Medical Expense Analysis** - Thorough cost analysis and documentation
- **Demand Letter Support** - Professional legal document preparation
- **Hyperlinks & Bookmarks** - Digital organization and cross-referencing
- **Expert Medical Opinions** - Professional medical expert analysis

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd quantyx-global

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Technology Stack

This project is built with modern web technologies:

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with shadcn/ui components
- **Routing**: React Router DOM
- **State Management**: TanStack Query
- **Icons**: Lucide React
- **Notifications**: Sonner

## Project Structure
